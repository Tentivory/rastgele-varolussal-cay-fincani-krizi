# Rastgele Varolussal Cay Fincani Krizi

Bu, dunyanin en ciddiye alinmamasi gereken ama bir o kadar da gercekten calisan programidir.

Amaci: Sana rastgele cay fincani, kasik, demlik vs. hakkinda varolussal krizler uretmek.

## Nasil Calistirilir?

```bash
python3 cay_krizi.py
```

Evet, bu kadar.

## Ozellikler

- Gercekten rastgele krizler uretir
- Cay ile ilgili her seyi sorgulatir
- Hicbir ise yaramaz
- Ama calisir
- %100 Turkce
